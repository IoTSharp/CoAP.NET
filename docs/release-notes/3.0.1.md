## 相对 3.0.0 收录的主干能力

- `AddCoapServer(IConfiguration)` 和 `AddCoapServer(CoapServerListenOptions)` 支持配置驱动注册；已有 `AddCoapServer(Action<CoapServerOptions>)` 继续保留。
- `CoapServerListenOptions` 绑定现有协议参数、UDP 开关、地址、端口及 DTLS PSK 设置。两种传输均关闭时不注册协议托管服务；无效地址、端口、缺失或空白 PSK 在注册时拒绝。
- `CoapServerOptions.ApplyListenOptions`、`ListenCoap`、`ListenCoapsPsk` 负责配置到端点的映射。DTLS channel 可绑定明确的 IPv4/IPv6 本地端点；旧的端口构造函数继续保留。
- server 创建时接入宿主 `ILoggerFactory`，监听配置由组件统一记录。协议生命周期继续由 Generic Host 管理。
- `CoapRouteContext.GetQueryValues` / `TryGetQueryValue` 解码 Uri-Query 键和值；默认区分大小写，可显式传入比较方式。多值按请求顺序返回，单值取最后一个匹配值，保留字面加号。
- ASP.NET Core 增加 `UseCoapServer()`；两种传输均关闭时跳过资源映射。`AddCoapResources()` / `MapCoapResources()` 继续作为推荐 Resource API。
- 配置绑定入口明确标注反射及动态代码要求。Native AOT 宿主应使用明确的监听配置对象或 options callback，并继续使用 generated endpoint 和 source-generated JSON。

这些能力来自 `a405086` 和 `f0af62d`，本轮仅将它们纳入可打包候选；不把租户、身份、业务鉴权、数据库、审计或事件总线引入协议组件。既有 client、Resource tree、Blockwise、Observe、discovery 和宿主策略扩展点保留。

## 兼容与回退

这是保持现有 `3.0.0` API 的增量补丁。普通宿主继续使用 `AddCoapServer`、`AddCoapResources` 和 `MapCoapResources`；依赖配置驱动接口的宿主需消费 `3.0.1` 候选或更高的实际已发布版本。

回退到 `3.0.0` 时，应同时回退核心与 ASP.NET Core 包及其宿主集成源码；`3.0.0` 不含本页列出的配置驱动扩展，不能只回退包版本后继续调用这些新增 API。未经正式发布与验证，不将候选标为生产可用。
